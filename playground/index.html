probbit playground: WebAssembly, one thread, no server

The probbit engine compiled to WebAssembly, running in this page without threads. decide routes tasks to workers under hard rules; evaluate takes a decision model's per-question probabilities plus your rules and returns the most likely answer set that obeys every rule, with odds and a gate that refuses instead of guessing. Edit the JSON and press Run (flags go in "flags", as in probbit mcp).
