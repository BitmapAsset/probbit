Meet three individuals from one persona


A persona file gives an agent a temperament that lives outside the model: traits with priors, moods, habits that are hard rules. A
different seed is a different, stable individual. Here three seeds of one persona live through the same scripted turns, computed in this
page (probbit persona, docs/persona.md): each turn is one probbit-ir program, answered exactly; the stance line is what a host puts
into any model's prompt. No model is called here: the persona decides how a reply is written, the model would write it.
