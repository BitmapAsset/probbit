# probbit Monitor (macOS app)

The `probbit monitor` page in a native Mac window, around a bundled probbit binary. Build: `./build.sh [--binary PATH]`;
check: `./smoke.sh "dist/probbit Monitor.app"`; icon: `./make-icon.sh`. How it works, signing and the first-launch steps:
[docs/monitor-app.md](../../../docs/monitor-app.md).
