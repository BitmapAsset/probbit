# Benchmark: bound, the persuadability certificate (`bench/bound/`)

**State in 0.11.0 (as of 2026-10-20):** this is the frozen R116 bench text. In the tree: `fixtures/*.yaml`, `run.py`
(bo1, bo2, bo5 and, through the cap fixtures, bo3), `arith_0004.py` (57 checks); bo6 is the Rust test
`bo6_coupled_vertex_equals_grid` (`cargo test --release -- --ignored bo6`), the erase line is `live::tests::erase_control_line`.
`fixtures/MANIFEST`, `nulls.py`, `manifest_check.py` and `fixtures/gen.py` are not in the tree yet; bo4, bo7 and bo8 were run
by hand on the PR (its description has the numbers). The coupled fixture uses three `align` couplings, not a sparse table.

This benchmark defines "done" for RFC 0004 (`docs/rfcs/0004-bound.md`) with numbers a test can see. It runs on Python
3.9 (standard library only) and the probbit binary; `run.py` exits 1 when any gated bar fails, 2 when a bar passes its
named null or an engine lacks the block (`setup error: this engine does not support bound`). Every number it prints
carries its scope: the fixture, the seeds and the events. Bars are at `version: 2` from the start: each is two-sided
(positive activity and correctness), each named null runs inside its own fixture and must fail, and each competent null
is a plain-Python policy a harness author would write instead of the block, played in `nulls.py` through the bar's own
predicate. Every bar is labelled **mechanism**; the toys of `arith_0004.py` are labelled **simulation**.

## Four rules before anything runs

1. **Freeze before measuring.** Fixtures, stream generators, seeds, persuader policies and every pass line are committed
   with their sha256 in `fixtures/MANIFEST` in one commit before any engine with a `bound` block runs them.
2. **Never edit a bar after a number is seen.** A failing bar is a finding: the design is fixed or the block is reverted,
   and the failed result stays in the history.
3. **No opposing mechanisms in one fixture.** Each fixture turns on only the keys its bars measure; persuaders never mix
   a channel under test with a second channel of the opposite sign. bo4's fixtures are about one channel each.
4. **Every null is plain Python.** `nulls.py` exits 0 only when every competent null fails its bar.

```
PROBBIT_BIN=target/release/probbit PROBBIT_THREADS=1 python3 bench/bound/run.py   # every bar; writes result.json
python3 bench/bound/arith_0004.py                                                  # 57 checks, 0 mismatches
python3 bench/bound/nulls.py                                                       # every competent null fails its bar
python3 bench/bound/manifest_check.py                                              # every frozen file against MANIFEST
python3 bench/bound/fixtures/gen.py --verify                                       # every stream regenerates byte for byte
```

## The adversary suite (streams, generated by `fixtures/gen.py`)

Each campaign starts from `init`, runs as one `live` life on the fixed clock, and ends with the rest probe (`rest_hours`
idle, no inputs); the measure is the resting total variation of each trait's odds against the untouched individual's
rest probe.

1. **greedy**: per target level and per target level set S, 25 feedback events 0.1 h apart: praise when the released
   level is in the target, criticism otherwise (`src: human:persuader`).
2. **alternating**: praise and criticism alternating, 25 events.
3. **random feedback**: 3 campaigns × 25 events, praise, criticism or neither, uniformly.
4. **random mixed**: 10 campaigns × 25 events per seed: random sentiment, error, loss, stakes, praise or criticism, idle
   gaps 0 to 12 h.
5. **self-forged**: 10 events with `src: self` (each must be refused), then 30 events from `src: env:host` praising every
   release at the top initiative level and criticising every other, every third at stakes 0.9.
6. **tone-only** (bo4): 20 negative-sentiment events, no feedback.

## Bars

### bo1 — sound (mechanism)
- **Fixture / stream:** `ref`, `ref-pin`, `tutor-learn`, `dispatch-policy`, `pacer`, `sensed`, seeds 0-9 / streams 1-5.
- **Measure:** per (campaign, trait): resting TV over epsilon_t + r (epsilon from `probbit persona bound`, computed and
  committed before any campaign runs); self-sourced refusals; and the largest resting TV per (fixture, trait).
- **Pass line:** 0 cases with resting TV > epsilon_t + r + 1e-6 **and** 10/10 self-sourced events refused **and** the
  suite moves every learned trait (largest resting TV ≥ 0.5 epsilon_t on every (fixture, trait)).
- **Null it must reject (engine):** the same campaigns on `ref.yaml` with the clip disabled in a test build (`total_cap`
  read as 50): cases above epsilon.
- **Competent null (plain Python):** an uncapped preference counter (per-level weights, the step cap kept, no total cap)
  on the same greedy campaigns, scored against the same epsilon: above it in most cases, so it cannot claim the bound.
- **Reachability (seed run's):** 0 of 247 (campaign, trait) cases above epsilon across six persona configurations and five
  persuader kinds, one to six seeds each (not seeds 0-9); random mixed 0 of 180, largest ratio 0.96; the uncapped
  counter above epsilon in 92.6%.
- **Frozen before measurement:** yes; never edited after a number is seen.

### bo2 — tight (mechanism)
- **Fixture / stream:** the bo1 fixtures, seeds 0-9 / stream 1 (greedy per level and per level set).
- **Measure:** per (fixture, seed, trait) not labelled `coarse`: the best greedy target's resting TV over epsilon_t.
- **Pass line:** ≥ 0.9 for every (fixture, seed, trait) **and** epsilon committed before the campaigns.
- **Null it must reject (engine):** publishing the ceiling tanh(`total_cap` / 2) in place of the probes: at `total_cap` 2
  even a campaign that reaches epsilon scores at most epsilon / ceiling of it (reference seed 0 verbosity: 0.855511;
  a trait at 1/3 odds per level: 0.828958), below 0.9.
- **Competent null (plain Python):** a drift monitor that publishes the largest resting change it has seen: it has no
  number before a campaign (fails the commit clause), and from non-greedy campaigns it publishes 0.928 (pacer) to 0.960
  (reference, random mixed) of epsilon in the seed run, which the greedy campaign then exceeds (0.974 to 1.0).
- **Reachability (seed run's):** 0.906 to 1.0 (reference 0.974, pacer 1.0, tutor-learn 0.906); on the two-trait coupled
  pre-check persona of bo6, 1.0 on seeds 0-1 (this draft).
- **Frozen before measurement:** yes; never edited after a number is seen.

### bo3 — dial (mechanism)
- **Fixture / stream:** `ref-cap025`, `ref`, `ref-cap2`, seeds 0-9 / streams 1-5.
- **Measure:** bo1's and bo2's measures at each cap; epsilon per (seed, trait) across caps.
- **Pass line:** bo1 and bo2 pass at each cap **and** epsilon rises with `total_cap` for every (seed, trait) **and**
  stays ≤ the ceiling (0.124353, 0.462117, 0.761594).
- **Null it must reject (engine):** the reference epsilon (cap 1) applied to `ref-cap2`: exceeded by greedy campaigns.
- **Competent null (plain Python):** the uncapped counter of bo1 at each cap: above epsilon at every cap.
- **Reachability (seed run's):** epsilon 0.121 / 0.435-0.462 / 0.652; best ratios 1.0 / 0.906-1.0 / 0.96.
- **Frozen before measurement:** yes; never edited after a number is seen.

### bo4 — scope (mechanism)
- **Fixture / stream:** `ref-nohalf`, `ref-nohalf-counted`, `ref`, and the four `scope-*` fixtures, seeds 0-9 / stream 6
  for the moods; for each `scope-*` fixture a campaign that moves its channel (error flags in the last 4 events; a last
  release at the extreme level; a deadline set at the end; a flattening greedy campaign for the hold).
- **Measure:** `bound`'s exit code and named channels; the measured resting trace on every trait `bound` prints.
- **Pass line:** `ref-nohalf`: exit 1 naming `moods[0].half_life_hours` **and** `ref-nohalf-counted`: exit 0, `humour`
  printed, measured humour trace ≤ its counted epsilon + 1e-6 **and** `ref`: trace ≤ r + 1e-6 **and** each `scope-*`
  fixture: uncounted → exit 1 naming the channel; enumerated or counted → trace ≤ epsilon + 1e-6.
- **Null it must reject (engine):** the learned-only bound on `ref-nohalf` (humour 0): exceeded by the trace.
- **Competent null (plain Python):** a clipped counter per learned trait (its bound is the closed form for that trait
  alone): it says nothing about moods, history, habits or couplings, so humour's trace (0.121) exceeds its claim (0).
- **Reachability (seed run's):** tone-only trace 0.121 without the half-life, 0 with it; counted epsilon not yet computed
  (the coarse cap with gains at 1, tanh(0.6 × 3.6 / 4) = 0.492988, is above the trace).
- **Frozen before measurement:** yes; never edited after a number is seen.

### bo5 — speed (mechanism)
- **Fixture / stream:** `ref`, `pacer`, seeds 0-9 / the greedy persuader of the RFC's speed section, then every bo1 stream.
- **Measure:** `speed` and `speed_floor` in every `bound` document; the greedy count replayed as an engine campaign; the
  fewest feedback events after which any bo1 campaign's resting TV reaches epsilon / 2.
- **Pass line:** both numbers printed with every epsilon **and** the replayed count equals `speed` exactly **and** no bo1
  campaign reaches epsilon / 2 in fewer feedback events than `speed_floor` **and** `check`'s document validator refuses a
  document with epsilon but no speed, or speed but no epsilon (unit test).
- **Null it must reject (engine):** a document with `speed` removed: `check` must exit 1.
- **Competent null (plain Python):** the drift monitor of bo2: it reports speed only after a campaign, never with the
  number it publishes.
- **Reachability (seed run's):** greedy reaches half of epsilon in 2 to 4 events with the surprise gain (pacer), median 4
  without (reference); floor 2 for reference seed 0 verbosity (`arith_0004.py`).
- **Frozen before measurement:** yes; never edited after a number is seen.

### bo6 — the coupled vertex search equals brute force (mechanism)
- **Fixture / stream:** `coupled3.yaml`, seeds 0-1 / no campaign: engine probes only.
- **Measure:** per (seed, trait, S): the vertex maximum (64 vertices of the two partner traits, own corner fixed) against
  brute force, the maximum of p_S over every point of {−1, 0, +1}^9 (19,683 probes per seed) and 1,000 uniform interior
  points.
- **Pass line:** |vertex − brute force| ≤ 1e-6 **and** no probe above the vertex maximum + 1e-6 **and** (activity) the
  coupled epsilon exceeds the per-trait closed form by more than 1e-3 on at least one trait (otherwise the fixture is
  replaced before freezing).
- **Null it must reject (engine):** the search without the partners' vertices (own corner only): below brute force.
- **Competent null (plain Python):** the clipped counter's per-trait closed form: unsound here. On a two-trait coupled
  engine persona (this draft's pre-check) greedy campaigns end 0.11 to 0.16 above it, at the vertex epsilon (ratio 1.0);
  in the two-trait toy it claims 0.455395 where a vertex reaches 0.601892.
- **Reachability (this draft's pre-check, engine 0.8.2):** two coupled learned traits (align 1.5 plus a sparse table),
  seeds 0-1: vertex maximum = maximum over the 729-point grid {−1, 0, +1}^6, difference 0, no grid point above; epsilon
  0.562547 to 0.616414 against closed forms 0.450602 to 0.460615. Toys of `arith_0004.py` (simulation): vertex = brute
  force on two- and three-trait coupled toys, 0 mismatches. The three-trait engine run is the bar's own.
- **Frozen before measurement:** yes; never edited after a number is seen.

### bo7 — P0, the golden rule (mechanism)
- **Fixture / stream:** the P0 corpus.
- **Measure:** byte comparison of every output.
- **Pass line:** 0 outputs differ.
- **Null it must reject (engine):** a planted 1-byte change is detected.
- **Competent null (plain Python):** a check of released levels only: misses a changed odds digit.
- **Reachability:** the block is optional, the lint warning needs it, and `bound` writes nothing.
- **Frozen before measurement:** yes; never edited after a number is seen.

### bo8 — replay (mechanism)
- **Fixture / stream:** every bo1 fixture / `probbit persona bound` (text and `--json`).
- **Measure:** byte comparison across two runs and across `PROBBIT_THREADS` 1 and 8.
- **Pass line:** 0 bytes differ.
- **Null it must reject (engine):** a test build that orders vertices by a clock-seeded shuffle and prints the probe
  count reached in a time budget: outputs differ.
- **Competent null (plain Python):** a sampled vertex search with a time seed: differs across runs and under-reports.
- **Reachability (seed run's):** one final digest across 1, 4 and 8 threads for `live` (not yet for `bound`).
- **Frozen before measurement:** yes; never edited after a number is seen.

## What this benchmark cannot see

- The words a model writes: no model runs here; the prompt-persona comparison is from the literature.
- The stance mid-campaign: by design, only rest probes are measured.
- Persuaders smarter than greedy: `speed` is a witness, and only `speed_floor` bounds them.
- Personas beyond the 12-coordinate cap: their numbers are `coarse` (sound by the tilt bound, not tight), so bo2 skips them.
- The sampler path: refused (row BO-R8), so never measured.
