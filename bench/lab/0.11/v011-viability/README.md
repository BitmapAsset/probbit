# The v-run: viability bounds and graded need pressure (0.11, one pre-registered run, 2026-10-21)

Mechanism and simulation. A seeded world with three resources (budget, integrity, recovery), each with a viability band,
400 steps per episode at 0.25 h a step, evaluation seeds 1000-1999, 1,000 episodes per arm. One resident probbit individual
per episode (`probbit live --clock fixed`, one event per step); the host sends only what it measured (spend, damage, strain,
tool failures, satisfying amounts) and the engine integrates its own deficits. Arms: **A** decides from the engine's stance
(`viability.worst` and the need margins; the host holds no band width), **B** the same policy on a constant resting stance,
**C** a threshold heuristic on the world's levels, **D** random, **A-t0** A with `needs.valence.tonic = 0`.

This kit reproduces BENCHMARKS.md §13 (bars V1-V4 and V7, the nulls, the tracking distributions), the 0.11 column of Table 3
in the technical report (survival, mean steps, prioritisation by arm) and figures a, b and c of `docs/results/0.11/` (their
v-run halves). The 0.10.1 column of Table 3 is the I3-sim kit, `../i3sim-needs-viability/`. The bars as registered before
the run: [PREREGISTRATION.md](PREREGISTRATION.md).

## Recompute every table (no API calls, no network)

```bash
cd bench/lab/0.11/v011-viability
python3 -m venv venv && venv/bin/pip install numpy==2.0.2
PROBBIT=$(command -v probbit) experiments/rerun.sh venv/bin/python
```

`rerun.sh` runs the harness twice from `experiments/config_baseline.json` (all five arms, 5,000 episodes each time), compares
the sha256 of the five tables with `tables/original.sha256` (the run's own tables) and with each other, prints
`tables: byte-identical (original, rerun 1, rerun 2)`, then verifies every strand it wrote with `probbit live verify`
(A 1,000 + 60 for each other arm = 1,240) and prints `strands: 1240 verified, 0 failed`. It exits 1 on any difference.
Strands and the generated persona documents go to `out/` (not committed). `git status --short tables` is empty after a
reproduction.

Wall time: 27 min 44 s (1,664 s) on a 16-vCPU Ubuntu 24.04 VM (two passes plus the strand verification); the lab's own `rerun.sh`
took about 4 minutes on an Apple-silicon Mac (`tables/rerun-twice.out`). The harness runs 8 processes in parallel.

## Files

| file | what |
|---|---|
| `experiments/world.py`, `policies.py`, `persona.py`, `bridge.py`, `run_arms.py` | the world, the four policies, the persona (a synthetic simulation persona, built in code), the host-to-engine bridge, the arms and the tables |
| `experiments/config_baseline.json` | the frozen configuration of the run (the I3-sim baseline world) |
| `experiments/rerun.sh` | the double rerun and the strand verification |
| `experiments/ablation.py`, `loop.py`, `loop_check.py`, `config_best*.json` | carried over unchanged from the I3-sim harness the v-run was copied from; not used by the v-run |
| `tables/arms_vrun.tsv`, `tracking_vrun.tsv`, `episodes_vrun.tsv`, `vbars_vrun.tsv`, `nulls_vrun.tsv` | the run's tables (`vbars_vrun.tsv` judges V1-V4) |
| `tables/original.sha256`, `rerun-1.sha256`, `rerun-2.sha256`, `rerun-twice.out`, `strand_*.txt` | the run's own replay record (V7) |
| `tables/frozen-harness.sha256` | the harness as frozen before the run; `bridge.py`, `run_arms.py` and `rerun.sh` differ from it only by the path lines listed below |
| `v6/compare247.json`, `v6/compare247.out` | V6 as recorded: 247 persuasion campaigns, each achieved resting change compared with the epsilon the engine published (0 over, max ratio 1.0) |

Path lines changed for publication (nothing else): `bridge.py` reads the binary from `PROBBIT`; `run_arms.py` writes
strands and personas under `out/`; `rerun.sh` takes the interpreter as its argument and the binary from `PROBBIT`.

## Not in this kit

- **V5's recorded strands and H1.** V5 also replayed seven recorded strands of a private deployment (196 events), and the
  host acceptance check H1 read the same strands; those strands and the tables that name them are not published. V5's other
  half, the 240 simulated strands, is the I3-sim kit's strand verification (`../i3sim-needs-viability/`).
- **V6's audit of two recorded strands** (0 exceedances): recorded strands of the same private deployment; not published.
- **V6's campaign harness.** `v6/compare247.*` is the recorded comparison; the scripts that ran the 247 campaigns belong
  to an earlier lab harness that is not published, so this kit does not re-run them. The bound itself is re-measured by the
  public bound bench on its own registered campaigns:
  `PROBBIT_BIN=target/release/probbit PROBBIT_THREADS=1 python3 bench/bound/run.py` (`bench/bound/BENCH.md`, bar bo1).
- **V5's `cargo test`** and the P0 corpus (`bench/individuality/p0.py check`, 653 recorded outputs) run from the
  repository itself, not from this kit.
