# V2 residual: what carries valence's tracking when the tonic term is off (one pre-registered run, 2026-10-21)

Mechanism and simulation. The v-run's V2 bar failed on its ablation clause: with `needs.valence.tonic = 0` (arm A-t0) the
median Spearman(valence, distance) was +0.1199 against a ceiling of +0.10. This follow-up runs the v-run's harness, binary,
world and seeds (`../v011-viability/`) with eight paired arms of 1,000 episodes, each switching off a pre-named set of
candidate channels into the valence mood:

| arm | tonic | phasic | `drives.valence` | sense couplings into valence (tool_fail −0.5, damage −0.3) |
|---|---|---|---|---|
| `A` | 0.8 | 0.6 | on | on |
| `A-t0` | 0 | 0.6 | on | on |
| `T0-P0` | 0 | 0 | on | on |
| `T0-D0` | 0 | 0.6 | off | on |
| `T0-S0` | 0 | 0.6 | on | off |
| `T0-all` | 0 | 0 | off | off |
| `A-P0` | 0.8 | 0 | on | on |
| `A-S0` | 0.8 | 0.6 | on | off |

This kit reproduces the V2 residual paragraph of BENCHMARKS.md §13 and Section 5.3 of the technical report: the A and A-t0
rows equal the v-run's to every printed decimal (R1); survival, prioritisation and pressure are identical on all eight arms
(R2); the medians +0.1199 (A-t0), −0.2674 (T0-P0), +0.1629 (T0-D0), +0.2868 (T0-S0), 0.0000 (T0-all, at the time-shuffle
null), +0.8316 (A-P0) and +0.9937 (A-S0) (R3); 1,420 strands verify. The bars as registered before the run:
[PREREGISTRATION.md](PREREGISTRATION.md). The published V2 of the v-run stays FAIL; this run explains the residual, it
does not re-judge V2.

## Recompute every table (no API calls, no network)

```bash
cd bench/lab/0.11/v2res-valence-residual
python3 -m venv venv && venv/bin/pip install numpy==2.0.2
PROBBIT=$(command -v probbit) experiments/rerun.sh venv/bin/python
venv/bin/python judge_v2res.py
```

`rerun.sh` runs the eight arms twice from `experiments/config_baseline.json`, compares the sha256 of the four tables with
`tables/original.sha256` and with each other, prints `tables: byte-identical (original, rerun 1, rerun 2): 4 files`, then
verifies every strand it wrote (A 1,000 + 60 for each other arm = 1,420) with `probbit live verify` and prints
`strands: 1420 verified, 0 failed`. `judge_v2res.py` reads only the tables (this kit's and `../v011-viability/tables/`) and
rewrites `tables/rbars_v2res.tsv` (bars R1-R3). Strands and generated persona documents go to `out/` (not committed).
`PROCS=<n>` sets the number of parallel processes (default 8; every episode is seeded, so the tables do not depend on it).
`git status --short tables` is empty after a reproduction.

Wall time: WALL_V2RES on a 16-vCPU Ubuntu 24.04 VM with `PROCS=PROCS_V2RES` (two passes plus the strand verification).
